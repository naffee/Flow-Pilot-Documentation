# Dashboard Overview

The FlowPilot Dashboard is your command center for monitoring and managing automations.

## Main Interface

![Dashboard Screenshot](https://placehold.co/800x400/e9ecef/495057?text=Dashboard+Interface)
*(Visual representation of the FlowPilot dashboard)*

### 1. Workflow Stats
The top row displays critical metrics for the last 30 days:
- **Active Workflows:** Number of currently running automations.
- **Tasks Executed:** Total number of successful action steps.
- **Time Saved:** Estimated hours saved based on task complexity.

### 2. Activity Feed
The **Activity Feed** provides a real-time log of workflow executions. You can filter this view by:
- Status (Success, Failed, Waiting)
- Workflow Name
- Date Range

> [!NOTE]
> Logs are retained for 30 days on the Standard plan and 90 days on the Pro plan.

### 3. Quick Actions
Access common tasks directly from the sidebar:
- **Templates:** Browse pre-built workflow templates.
- **Apps:** Manage your connected integrations.
- **Settings:** Update team members and billing information.
