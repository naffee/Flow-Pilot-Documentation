# Usage Limits

To ensure fair usage and system stability, we enforce certain limits.

## Workflow Execution

- **Max Runtime:** 10 minutes per workflow.
- **Max Steps:** 50 steps per workflow.
- **Payload Size:** 5MB max payload per step.

## API Limits

- **Rate Limit:** 60 requests per minute for Standard API endpoints.
- **Burst Limit:** Up to 100 requests per minute for short durations.

If you need higher limits, please contact our sales team.
