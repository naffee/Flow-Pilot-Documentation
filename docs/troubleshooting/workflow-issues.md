# Workflow Not Running

If your workflow isn't triggering as expected, check the following:

1. **Is the workflow active?** Ensure the toggle in the top right is set to **ON**.
2. **Check the Trigger History:** Sometimes the trigger app doesn't send data immediately.
3. **Filter Conditions:** Verify that your trigger filters aren't too restrictive (e.g., looking for a specific subject line that doesn't match).

## Debug Mode

Enable **Debug Mode** in the workflow settings to see detailed logs of every step execution, including raw input and output payloads.
