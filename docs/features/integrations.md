# Integrations

FlowPilot connects with the tools you use every day. We support over 200+ native integrations and thousands more via webhooks.

## Popular Integrations

| Category | Apps |
| :--- | :--- |
| **Communication** | Slack, Microsoft Teams, Discord, Gmail, Outlook |
| **CRM** | Salesforce, HubSpot, Pipedrive, Zoho CRM |
| **Project Management** | Jira, Trello, Asana, Linear, Notion |
| **Database** | PostgreSQL, MySQL, Google Sheets, Airtable |
| **Marketing** | Mailchimp, Twitter (X), LinkedIn, Facebook Ads |

## Connecting an App

1. Go to the **Apps** section in the dashboard.
2. Click **Add Connection**.
3. Search for the application.
4. Follow the OAuth authentication flow.

> [!NOTE]
> Custom integrations can be built using our HTTP Request node or by creating a custom connector via our Developer API.
