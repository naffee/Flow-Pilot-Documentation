# Analytics & Reporting

Gain insights into your automation performance with FlowPilot's comprehensive analytics suite.

## Dashboard Metrics

- **Success Rate:** The percentage of workflow executions that completed without error.
- **Average Duration:** How long each workflow takes to run.
- **Credit Usage:** Track your AI token consumption and task usage against your plan limits.

## Exporting Data

You can export execution logs and performance reports in the following formats:
- CSV
- JSON
- PDF

## Custom Reports (Enterprise)

Enterprise customers can create custom dashboards using SQL-based queries to visualize specific KPIs relevant to their business.
